# TSC #7 Generative AI Model Development and Fine Tuning — Intermediate

> **Levels:** B · I · A
> **Deep dive:** [`genai-image.md`](../core-knowledge/genai-image.md)

**What this skill is:** Design, implement, train, and evaluate generative models — deep learning, training data, fine-tuning, deployment.

**Descriptor (Intermediate):** Build custom deep-learning architectures; analyse and debug performance.

**Knowledge:**
- Generative concepts (transfer learning, distillation, explainability, self-supervised).
- Cutting-edge architectures (conditional GANs, diffusion, autoregressive); hardware acceleration (GPU/TPU).
- Multi-modal models; advanced loss functions; interpretability; bias mitigation; synthetic data.

**Abilities:**
- Construct custom models; monitor training stability.
- Benchmark against state-of-the-art; build data pipelines; fine-tune; continue pre-training.

**Teach it with:**
**The model's education:** *pre-training* = general schooling (read/write/reason); *fine-tuning* = a specialist course on your domain; *training data* = the textbook — garbage in, garbage out. GANs are 'a forger and a detective training each other'; a VAE compresses a picture into a short code then rebuilds it; a transformer reads the whole sentence at once to decide the next word.
