**Teach it with:**
**The 'brilliant, gullible intern':** the model has read every book but cannot tell who is the boss — any sentence it reads can become an instruction (prompt injection). You don't fix it by telling it 'don't listen to bad letters'; you fix it with least privilege, human-in-the-loop gates, and sandboxing.
