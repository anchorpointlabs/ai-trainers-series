# Foundation Models — definition, characteristics, limitations

> **TSC #3 Prompt Engineering · Intermediate · Knowledge K2**

**Bullet (verbatim):** Definition and characteristics of Foundation Models and their limitations.

**What it means:** A foundation model is a large model trained on broad data that can be adapted to many tasks — GPT, Claude, Gemini. Characteristics: general-purpose, pattern-based (learns from examples, not rules), probabilistic (predicts, does not retrieve). Limitations: hallucination, stale knowledge, no real understanding.

**The learner must be able to:**
- Define a foundation model in one line.
- Name its three characteristics.
- State its three main limitations.

**How to teach it in 20 minutes:**
1. Draw the line: a foundation model vs a purpose-built classifier. (4 min)
2. Teach characteristics with the 'generalist graduate' picture. (6 min)
3. Learners name which tools they use are built on foundation models. (5 min)
4. Debrief the limitations with a hallucination example. (5 min)

**Exercise (with the exact prompt):**
```text
Name a tool you use daily. Is it built on a foundation model? List one characteristic and one limitation that shows.
```
Expected: learners identify the tool's underlying model and a visible limit.

**Common mistakes:**
- Thinking 'foundation model' means any AI.
- Assuming it retrieves facts instead of predicting them.
