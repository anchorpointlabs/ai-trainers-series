# TSC #9 Generative AI Models — Technical Aspects of Security and Ethics — Intermediate

> **Levels:** B · I · A
> **Deep dive:** [`ai-security.md`](../core-knowledge/ai-security.md)

**What this skill is:** Keep AI models and systems secure and ethically sound — from development through deployment and operation.

**Descriptor (Intermediate):** Implement security measures, configure guardrails, monitor compliance.

**Knowledge:**
- In-depth AI security measures and testing.
- Guardrail configuration; risk-assessment methodologies.
- Trust-and-safety best practice (risk matrix, bowtie, agile risk).

**Abilities:**
- Develop mitigation strategies; implement security measures (prompt-hack defence).
- Configure guardrails; run risk assessments and pre-deploy testing; monitor throughout the lifecycle.

**Teach it with:**
**The 'brilliant, gullible intern':** the model has read every book but cannot tell who is the boss — so any sentence inside a document can become an instruction (prompt injection). You don't fix this by telling it 'don't listen to bad letters'; you fix it with least privilege, human-in-the-loop gates, and sandboxing — steel turnstiles, not polite signs.
