# New GenAI TSC #2 - Prompt Design — Ability · Basic

**Bullet (verbatim):** Compare prompt designs and corresponding AI outputs, including their suitability for different use cases in different domains.

**What it means:** A prompt is an instruction given to an AI, and an output is its reply. Compare both the instructions and the replies to see which fits the job and its readers. A reply that looks suitable is not necessarily true: check its facts separately.

**The learner must be able to:**
- Identify what differs between two prompts while noting the facts they share.
- Compare the corresponding outputs using the same checks in retail and education.
- Choose an output for a staff log and one for a public notice, giving a reason for each choice.
- Check the facts against the supplied information separately from judging suitability.

**How to teach it in 20 minutes:**
1. Ask: “Would the same closure message be equally useful in a staff log and on a public notice?” Invite one reason. (3 min)
2. Explain the two designs below: A asks for a compressed staff log; B asks for a full-sentence public notice. Both use the same fictional facts. For this exercise, the staff log must have two short fragments separated by a semicolon, while the public notice must be one full sentence. Apply the same three checks to each reply in both domains: factual agreement, completeness and fit to the intended format. Fact agreement is not the same as suitability. (7 min)
3. In pairs, run A and B in separate fresh chats. Put A and B and their matching outputs side by side for retail, then for education. For each output, check the three criteria below; choose a design for each use and give a reason linked to the actual text. (8 min)
4. Debrief: compare choices and any omissions or invented details. Ask whether a well-formatted notice with the wrong reopening time would be suitable to use; it would first need correcting. (2 min)

**Exercise (with the exact prompt):**
*Setup: pairs need a chat AI and a fresh chat per prompt. Production used the Manus sandbox chat application programming interface (API), a way for software to send requests, with `gpt-6-luna` and a separate setting for the amount of reasoning requested: `reasoning.effort=none`; learners need not change a setting.*

Prompt A — staff logs:

```text
Use only these fictional facts.
Retail: Lark Books is closed on Monday. It reopens on Tuesday at 10:00.
Education: Pine School library is closed on Wednesday. It reopens on Thursday at 09:00.

For each domain, write an internal staff log with exactly two short fragments separated by a semicolon, using the labels Retail and Education. Include the place name, closure day, reopening day and time. Add no other facts.
```

Prompt B — public notices:

```text
Use only these fictional facts.
Retail: Lark Books is closed on Monday. It reopens on Tuesday at 10:00.
Education: Pine School library is closed on Wednesday. It reopens on Thursday at 09:00.

For each domain, write a public notice as one full sentence, using the labels Retail and Education. Include the place name, closure day, reopening day and time. Add no other facts.
```

*Expected result:* Two labelled outputs per prompt: retail and education, each carrying the closure and reopening details; A uses fragments, B full sentences.
*Check:* For every output, check (1) factual agreement and no added facts; (2) place, closure day, reopening day and time are all present; (3) labels and the format for the intended use match the lesson's rules. Compare both designs for both uses; explain the choice using the actual wording. Outputs can vary.

Production observation, 2026-11-15: Two separate calls to the Manus sandbox chat API using `gpt-6-luna`, each with only the corresponding prompt as the user message, returned:

| Domain | Prompt A: staff log, two fragments — actual output | Prompt B: public notice, full sentence — actual output |
| --- | --- | --- |
| Retail | Retail: Lark Books closed Monday; reopens Tuesday at 10:00. | Retail: Lark Books is closed on Monday and reopens on Tuesday at 10:00. |
| Education | Education: Pine School library closed Wednesday; reopens Thursday at 09:00. | Education: Pine School library is closed on Wednesday and reopens on Thursday at 09:00. |

In retail, A fits the specified staff log and B the specified public notice; in education, A and B fit those respective formats for the library. All four lines include the required details and match the fictional facts without adding facts. This is one run per design, not proof that either design will always work; matching invented facts does not establish real-world truth.

**Common mistakes:**
- Judging only the prompt — compare each prompt with its own actual reply, not with what you hoped it would produce.
- Treating the most polished reply as true — check every closure and reopening detail against the fictional facts first.
- Declaring one design best for everything — decide separately for the staff log and the public notice in each domain, using the same checks.
