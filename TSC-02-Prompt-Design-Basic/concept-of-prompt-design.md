# Concept of prompt design

> **TSC #2 Prompt Design · Basic · Knowledge K7**

**Bullet (verbatim):** Concept of prompt design.

**What it means:** A chat AI (artificial intelligence) tool generates text in response to a message. A prompt is a message you give such a tool, such as a request to write a notice. Prompt design means deciding what you want the tool to do and giving it relevant background, such as the audience and facts it needs. It is not about finding magic wording: use ordinary, clear instructions, then check the reply.

**The learner must be able to:**
- Explain prompt design as specifying a task and relevant background, rather than finding a magic phrase.
- Identify the task and the relevant background in a prompt.
- Check a generated notice against the supplied facts and requested length.

**How to teach it in 20 minutes:**
1. Ask: if a colleague asks for a club notice but gives no details, what would you need to write it? Collect two suggestions. (3 min)
2. Use the exercise below to show the task: write a two-sentence notice for members. Point out the relevant background: the meeting date, time, room change and reason. Ask learners for a task and relevant background from an invented example of their own; explain that no special phrase is needed. (7 min)
3. In pairs, learners underline the task and circle the background in the prompt below, then run it in a new chat. They check the notice against the criteria below. (8 min)
4. Ask which detail, if any, was missing or wrong in the replies and why a clear prompt still needs a check. Note that replies can vary. (2 min)

**Exercise (with the exact prompt):**
Setup: Use a chat AI in a new chat; an account may be needed, no files are needed, and all the details below are invented.

```text
Write a two-sentence notice for members of the fictional Meadow Book Club. Tell them their next meeting is on 18 June at 3 pm in the Blue Room, rather than the Green Room. The change is because the Green Room is being painted. Use only these details and do not add any new ones.
```

Expected result: A two-sentence notice tells club members about the meeting and the room change.  
Check: Confirm 18 June, 3 pm, Blue Room instead of Green Room, and the painting reason; check that no new facts were added. Replies can vary.

**Common mistakes:**
- Searching for a magic phrase — state the task in ordinary, clear words instead.
- Omitting relevant background — include the audience and facts needed for this task.
- Assuming the reply must be right because the prompt is clear — check it against the supplied facts and requested length.
