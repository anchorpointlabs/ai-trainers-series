# TSC #1 Generative AI Principles and Applications — Basic

> **Levels:** B · I
> **Deep dive:** [`agentic-ai.md`](../core-knowledge/agentic-ai.md)

**What this skill is:** Understand and apply the concepts, frameworks, applications, and implications of generative AI — and judge where it is (and is not) appropriate.

**Descriptor (Basic):** Use generative AI to carry out specific tasks.

**Knowledge:**
- Fundamental purpose of GenAI — analysis + content in text, image, video, code.
- Fundamental concepts/theories; popular models + machine learning.
- Transformative potential, where GenAI works and where it does not.
- GenAI vs other AI paradigms; limitations of models.
- Responsible AI fundamentals; data privacy (PDPA) fundamentals.

**Abilities:**
- Write prompts to generate different output types.
- Analyse the accuracy and relevance of outputs for a task.
- Identify sensitive information; apply basic anonymisation (masking, perturbation, pseudonymisation).
- Consider responsible AI when applying GenAI.

**Teach it with:**
**The 'what GenAI actually is' line:** a model is a word-completion engine that got trained on half the internet — it predicts the next token, not the truth. Teach 'what it is for' (analysis, drafting, image/video/code) before 'how to prompt it'. The learner's first habit: check the output against the source, and know which data must never be entered (PDPA).
