# TSC #2 Prompt Design — Basic

> **Levels:** B
> **Deep dive:** [`prompting.md`](../core-knowledge/prompting.md)

**What this skill is:** Craft effective prompts to shape outputs and elicit desired responses — the AI-user level of prompting.

This folder is **complete** — 15 entries (K1–K7, A1–A8), one per knowledge/ability item.

**Knowledge:** concept of prompt design · how prompts shape content · prompt construction (zero/one-shot, domain-based, instruction, temperature & sampling) · impact on output modes · troubleshooting · data privacy · guardrails.

**Abilities:** define prompt elements · describe techniques · compare designs and outputs · identify best practice · recognise AI-tool issues · follow troubleshooting · apply anonymisation · identify misuse and risk.

**Teach it with:** a prompt is a brief to a very fast new hire — state the task, audience, facts and constraints in plain words, then check the reply. There is no 'magic phrase'.
