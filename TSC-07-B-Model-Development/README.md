# TSC #7 Generative AI Model Development and Fine Tuning — Basic

> **Levels:** B · I · A
> **Deep dive:** [`genai-image.md`](../core-knowledge/genai-image.md)

**What this skill is:** Design, implement, train, and evaluate generative models — deep learning, training data, fine-tuning, deployment.

**Descriptor (Basic):** Implement models based on existing architectures and evaluate them.

**Knowledge:**
- Deep learning theory (GANs, VAEs, Transformers).
- ML libraries; probability/statistics (latent variables).
- Data preprocessing and cleaning; embeddings and tokenisation.
- Loss functions and metrics; fine-tuning (SFT, parameter-efficient); dataset formats; parallel training.

**Abilities:**
- Select and implement appropriate models; preprocess data.
- Train on benchmark datasets; identify limitations and improve.

**Teach it with:**
**The model's education:** *pre-training* = general schooling (read/write/reason); *fine-tuning* = a specialist course on your domain; *training data* = the textbook — garbage in, garbage out. GANs are 'a forger and a detective training each other'; a VAE compresses a picture into a short code then rebuilds it; a transformer reads the whole sentence at once to decide the next word.
