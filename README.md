# APL: AI Trainer's Series

A reference library for AI trainers. One entry per skill from the IMDA/SkillsFuture *Skills Framework for ICT: Skills in Generative AI*.

Each entry has:
- The skill bullet in plain words
- A 20-minute teaching plan
- A tested exercise with the exact prompt
- Common mistakes
- Dated sources

## Structure

One folder per TSC and level. Entries are named `[TSC]-[number]-[K or A].md`.

| Folder | TSC | Level | Entries |
|---|---|---|---|
| `TSC-02-Prompt-Design-Basic/` | #2 Prompt Design | Basic | 15 |

More modules in progress.

## Source framework

IMDA / SkillsFuture — *Skills Framework for Infocomm Technology (ICT): Skills in Generative Artificial Intelligence (AI)*.

Individual bullets are quoted with attribution per IMDA terms of use. The full bullet list is not reproduced here.

## Expert level

Entries marked **APL Expert** are Anchor Point Labs additions. They cover agentic AI and are not part of the SkillsFuture framework.
